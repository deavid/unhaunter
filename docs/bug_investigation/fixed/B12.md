# B12 - Cannot grab map entities

## Symptoms

- Furniture/chairs cannot be grabbed, no reaction.

## Investigation

- Check interaction logic for map entities.
- Ensure they are correctly identified as grabbable on clients.

## Findings

- Map entities (furniture, etc.) were missing `Owner` and `LocallyOwned` components on the server/authority.
- Without `Replicated` (which was only added to some entities), clients couldn't interact with them over the network.
- Action: Updated `process_and_spawn_tile` in `unmapload-plugin/src/tile_spawning.rs` to ensure all replicated map
  entities (where `beh.p.is_replicated` is true, which includes pickable items) are spawned with `Replicated`,
  `Owner(OwnerId::Server)`, and `LocallyOwned` on the authority.

## Testing

FIXED - Refactored ownership architecture. Possession (`LocallyOwned`) is now derived strictly from `PlayerGear` slots
synced from the server. This allows furniture items correctly identified in `held_item` to be shielded correctly on the
client.
