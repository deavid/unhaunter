# B08 - Display room code in PAUSE menu

## Symptoms

- Room code is missing from the pause menu.

## Investigation

- Room code is in `RoomAuth::room_code`.
- Need to display it in the pause menu UI in Orange and big letters.

## Findings

- Room code is stored in `unreplicon_core::resources::RoomIdentification`.
- Added `font_kode_bold` to `PauseAssets` to match the lobby room code style.
- Updated `setup_ui` in `unpause-plugin/src/systems/pause.rs` to display the room code in orange when available.
