# B24 - Stairs visibility bleeds backwards via omnidirectional light

## Symptoms

- When a player looks at stairs to view another floor, if the destination floor is very bright, the visibility logic
  switches from a directional cone to an omnidirectional 360º spread.
- This causes the visibility to bleed backwards, occluding the player and making the view confusing.

## Investigation

- The issue lies in the 3D isometric visibility rendering (`unlight` or presentation layers), not the 2D fog-of-war
  (`unfog`).
- Review the recent addition that makes visibility conical based on darkness. The algorithm needs to handle extreme
  brightness differently when calculating cross-floor propagation.
- Ensure the visibility propagation strictly remains conical, projecting _away_ from the player when traveling up/down
  stairs, ignoring the ambient brightness of the destination floor.
