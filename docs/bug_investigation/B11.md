# B11 - Ghost transparency

## Symptoms
- Ghost is too transparent (goes to 0% alpha).

## Investigation
- Find ghost rendering/opacity logic.
- Enforce a minimum alpha of 0.1.

## Findings
- `ghost_clarity_sync` in `unghost-presentation/src/systems/visual_sync.rs` sets `clarity.alpha` based on `dynamics.visual_alpha_multiplier`.
- This alpha value is used for rendering the ghost.
- Action: Clamp `clarity.alpha` to a minimum of 0.1, except when the ghost is dying/dead (where it should still be able to go to 0.0).
