# B06 - Repellent swap should be free

## Symptoms

- Swapping a full, unopened repellent for another type charges the player (uses one of the 3 mission charges) and might
  return the old liquid.

## Investigation

- Check `handle_craft_repellent_request` in `ungearitems-logic/src/systems/common.rs`.
- Implement logic to check if existing repellent is full and unopened before "charging" for a new one.

## Findings

- Updated `truckui_event_handle` in `untruck-plugin/src/systems/truck_ui_systems.rs` to check for a full, unopened
  `RepellentFlask` in the player's inventory before decrementing the `RepellentCraftTracker`.
- If a full flask is found, it is refilled with the new ghost type without consuming a mission charge.

## Testing

This might be a second effect of the bug described in B16 - there might be a bug that causes random repellent creations
to be missed.
