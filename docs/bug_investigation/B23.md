# B23 - Flashlight overheat sound spams per-frame in multiplayer

## Symptoms

- When a flashlight overheats and turns off, it plays a warning "ding ding ding" sound.
- In multiplayer, this overheat sound spams repeatedly (seemingly once per frame) instead of playing just once,
  overwhelming the audio.

## Investigation

- Check the flashlight overheat logic (likely in `ungearitems-logic` or `ungear-plugin`).
- Ensure the state transition from "active" to "overheated" is properly debounced and only triggers the audio event
  once.
- Check if the rapid state replication is causing the client to re-evaluate the transition on every network update tick.
