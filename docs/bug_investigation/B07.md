# B07 - Repellent charges should be shared

## Symptoms
- Creating repellents is not shared between players.
- One player consuming a repellent in the truck doesn't reflect for others.

## Investigation
- Need a shared mission-wide counter for repellents (max 3).
- Move the counter to a replicated state.

## Findings
- Replicated `RepellentCraftTracker` by adding it to `MissionGoalEntity` on the server and syncing it to clients.
- Added replication rules in `unreplicon-plugin/src/systems/ghost.rs`.
- This ensures all players share the same mission-wide repellent craft limit.

## Testing

They are not shared.
