# B05 - Walkie lady (unwalkie) doesn't work on multiplayer

## Symptoms
- Walkie lady audio is never heard in multiplayer.
- Expected for evidence tips.

## Investigation
- Check `BroadcastWalkieEvent` and `ProposeWalkieEvent` logic.
- Ensure audio variation selection is deterministic across clients.

## Findings
- Walkie events are broadcast from the server using `BroadcastWalkieEvent`.
- `receive_walkie_broadcast` in `unwalkie-plugin/src/walkie_net.rs` receives this but currently skips it if the local instance has `AuthorityRole`.
- The user reports walkie lady doesn't work on multiplayer. This might be because the server broadcasts it but clients aren't playing it correctly or it's not being sent.
- Also need to ensure all players hear the SAME voice line.
- Action:
    - Add a `seed` field to `BroadcastWalkieEvent` (DONE).
    - Update `WalkiePlay.set_forced` to accept a seed (DONE).
    - Update `WalkiePlay.set` (server-side) to generate a seed (DONE).
    - Update `walkie_talk` to use a deterministic RNG based on `walkie_play.current_seed` (DONE).
    - Added diagnostic logging to `WalkiePlay` and `walkie_talk` to track queuing and state transitions.
