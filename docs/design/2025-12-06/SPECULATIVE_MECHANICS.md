## The Parallel Simulator Architecture

Two simulation engines in parallel:

1. **Physics Engine** (Light, Sound, Heat, Motion)
2. **Folklore Engine** (The "Magic" Logic)

The game IS the friction between them.

### The "Illiterate Tool" Concept

Tools aren't broken (random), they're **illiterate** (measuring the wrong thing). EMF beeps = Magnetic Field, not Ghost.
Tech sees **symptoms** of a logic it doesn't understand.

**Examples:** Entity extracts heat without gradient. Entity opaque to infrared. Entity exists in additional dimensions.

### Triangulation Through Conflicting Data

- Thermometer: -10°C (Freezing)
- Thermal Camera: Room glowing Hot
- Realization: Entity absorbs heat (thermometer drops) but converts to spectral energy (camera glows)

**Impact:** Can't rely on one tool. Must set up multiple sensors, compare, think. Transforms "Hunt the Ghost" to
**Forensics of the Paranormal**.

### The Calibration Moment

How to teach without tutorials:

1. Player sees chair slide
2. Motion sensor doesn't trigger
3. Realization: "Force has no physical mass/heat"
4. Lesson: Eyes are primary. Tools are filters.

**Test:** Would this recreate "The Ring" organically, or be comedic?

## Field Theory: Magic as Physics

Convert everything into fields. Multiple mystic fields interact with physical fields, creating emergent "magic" on
consistent rules.

### Sha Qi and Sheng Qi (Feng Shui)

- **Sha Qi:** Aggressive/negative (sharp corners, "poison arrows")
- **Sheng Qi:** Beneficial/positive (curves, flowing water)

**Wrong approach:** "Sharp corner = instant penalty" (gamified, scripted)

**Simulation approach:** Sha/Sheng as paired fields (like complex number). Statue emits Sha ray, ray propagates, player
moves mirror, ray reflects, interacts with other fields. **Emergent gameplay.**

| Gamified                       | Simulation                         |
| ------------------------------ | ---------------------------------- |
| Sharp corner = instant penalty | Sharp corner emits spreading field |
| Northeast always dangerous     | Field flow biased by geometry      |
| Install fountain to cure ghost | Water redirects field flow         |
| Static, memorizable            | Emergent, requires observation     |

**Goal:** Player feels **texture** of rule but doesn't see **code**. "Deterministic chaos"—between random (frustrating)
and scripted (boring).

**Caution:** Needs validation through prototyping.

## Geomantic Ballistics: The Kimon Axis

**Problem with naive implementation:** "Northeast = max EMF always" makes all maps same, exploitable in 3 hours.

### The Mechanic

- Maps: North on top, orthogonal hallways (N-S or E-W)
- Kimon flow: NE→SW diagonal
- No map has clear diagonal path—grid prevents it

**How it works:**

1. Entity drains from SW, attacks from NE
2. Like wormhole—but must bend magnetic field first
3. **Symptom:** Compass points diagonal (impossible in grid world)

**Counter-play:**

- Read compass for attack vector
- Move off diagonal, into room, or perpendicular hallway
- "Turning" is difficult for entity

**Result:** Dynamic "Kill Zones" that shift. Rewards positioning. Feels like magic physics.

**Note:** One possible mechanic, not universal law. Different entities = different mechanics.

## The Exhaust Theory

**Humidity as Entity Exhaust:** Entity generates entropy (Cold/Wet/Static) as waste.

- High saturation = entity stronger OR player takes damage
- Vent room to lower "Spiritual Pressure"—temporary window to enter
- Venting makes noise → might attract entity
- **Tactical tradeoff:** "Clear fog to see clue, but fan tells it I'm here"

| Wrong                       | Correct                      |
| --------------------------- | ---------------------------- |
| Fix HVAC → ghost disappears | Vent room → temporary window |
| Repair pipes → weaken ghost | Drain area → safe passage    |
| Contractor mindset          | Engineer mindset             |
| Solving the problem         | Buying time within it        |

**Key:** Environment **reflects** ghost, doesn't **cause** it. Use dampness as forensics ("ghost passed here"), not
exorcism.

## The Virology Model: Keeping Veterans Scared

**Problem:** Mastery = pattern recognition → horror dies → becomes a job.

**Requirement:** Fear of unknown should NOT disappear. Late game = "I know what I'm doing... I think."

### Solution: Procedural Logic (Not Just Maps)

Random maps aren't enough. The **rules themselves** must be variable.

**Virology analogy:** Know HOW viruses work, but new Hot Zone = new strain. Does this one die in heat or reproduce
faster? Test to find out.

**Veteran Experience:**

1. Assumption: "Scratching = Poltergeist. Use salt."
2. Violation: Salt fails. Entity walks through.
3. Horror: "Not a Poltergeist. Or a Variant. Safety net gone."

### Achieving "Infinite Unknown"

**Randomize cause & effect:**

- Run A: Mirrors dangerous
- Run B: Mirrors only safe place
- Run C: Mirrors inert, windows dangerous

**Emergent drives:** Instead of "Ghost Type X", simulate drives (Hunger for Sound, Fear of Light, Territorial over
Kitchen). Mix randomly → never seen this combination.

**Risk:** Too random = unfair. **Mitigator:** Forensics environment always has clues. If salt dangerous → salt in
kitchen already black.

### What Mastery Actually Looks Like

**NOT:** Speedrunning, memorized patterns

**YES:** Deep thought, calculated risks, building mental profile, planning navigation

**Mastery ≠ Knowing Answers. Mastery = Knowing how to ask questions without dying.**

## The Two-Way Interaction Concept

Every device is a **transducer**—converts spiritual energy to electrical/visual/auditory. Creates two-way street.

**Examples:**

- **Camera:** See entity's perspective, but lens becomes eye for entity to look back
- **Microphone:** Hear whispers, but the more you listen → more it influences your thoughts
- **Motion Sensors:** Map entity's attention, not just movement

**"Legible Noise":** Without tools, entity is unreadable scary. Devices create interpretable patterns. But tech attracts
and focuses haunting—device = lure.

| Tool            | Function                  | Risk                           |
| --------------- | ------------------------- | ------------------------------ |
| Reel-to-Reel    | Records emotional residue | Whispers give false directions |
| CRT + Camera    | Static patterns = mood    | Entity looks back through lens |
| Psiometer       | Dial: Calm→Malevolence    | Imprecise, panic soundtrack    |
| Salt/Chalk/Iron | Shows where things been   | Doesn't stop anything          |
| Polaroid        | Shows invisible truth     | Flash draws attention          |

## The Network Infrastructure Concept

> From 04_simulation_philosophy.md

### Core Concept

You aren't just walking around. You're establishing **infrastructure**.

- Running cables, placing repeaters, triangulating signals
- Turning a dark, chaotic room into a monitored "lab"

### The Simulation Elements

1. **Physics-Based Chain Reactions:**

   - Entity emits Cold → Cold affects Battery Life → Low battery affects Light → Low light invites Aggression
   - It's a chain reaction you can interrupt

2. **The Network:**

   - Establishing infrastructure throughout the location
   - Creating a monitored, controlled environment within chaos

3. **The Control:**
   - You don't "shoot" the lion. You build a fence.
   - Use data to manipulate entity's environment
   - Heat a room to force it out
   - Create noise loop to trap it in hallway

### The Core Emotion: Fragile Competence

> "You are intelligent, you have tools, and you can build systems. But you are building them on shifting sand. You never
> feel 'safe,' you only feel 'prepared enough for now.'"

## Door States Framework

> From 13_entity_as_immune_system.md

### The Door as Barometer

The door isn't a scripted event—it's a **barometer of your standing with the entity**.

### The Four States

#### 1. The Open Door (The Lure)

- House _wants_ you to enter, or doesn't care yet
- You can leave at any time
- **The Coward's Exit:** Walk in, realize vibes are too rancid, just leave. Survive but gain nothing.

#### 2. The Escalation (The Glare)

- Opening drawers, uncovering mirrors, stepping on "bad" tiles → attention shifts
- Door doesn't lock yet, but hallway might get longer, lights in foyer die
- Warning: "You are overstaying your welcome"

#### 3. The Provocation (The Grab)

- Touch the Extraction Target (doll, tape, bone) → become a Virus
- Entity wants to keep you—not because it loves you, but you're stealing part of _It_
- Exits seal. Reality warps. Hunt begins.

#### 4. The De-escalation (The Bargain)

- Put it back. Back away. Apologize (maybe literally via mic).
- Entity checks: Threat removed.
- Pressure lifts. Door unlocks.
- Leave empty-handed, shamed, but alive.

### The Conversation with the House

Pacing becomes a **physical conversation**:

- _Player:_ "I'm going to take this."
- _House:_ "I will kill you." (Door slams)
- _Player:_ "Okay, never mind, I put it back!"
- _House:_ "Get out." (Door opens)

**Forces constant evaluation:** "Am I ready to commit to the theft?"

## Pre-emptive Anger Mechanic

> From 13_entity_as_immune_system.md

### The Breakthrough

Entity can get angry just because it _thinks_ you're gonna steal.

### The Logic

- You start placing salt lines
- To you: safety
- To entity: you're building a cage
- **Reaction:** Attacks before you touch object

### The Strategic Dilemma

- **Naked Run:** No defenses → entity calm, but defenseless when you grab
- **Fortress Run:** Set up defenses → entity aggressive immediately, but safe path out

### The "Inexplicable" Hunt Explained

- _Player:_ "I didn't touch anything! Why did it hunt?"
- _Reality:_ You stood in Master Bedroom (its territory) for 3 minutes. That loitering was a challenge.
- _Exploitation:_ Use teammate as "Bait"—have them loiter to draw aggression while you sneak to basement

## Spatial Scarcity (Not Resource Scarcity)

David hates resource scarcity—makes him avoid using items entirely.

**Alternative:** Logistical/Spatial Scarcity.

**Resonance Concept:** Powerful items interfere when close. Two near each other → effects negate, resonate, problem
increases. Forces planning layout.

**The Feeling:** "Have the solution but can't find safe place to put it." Factorio-style desperation—spatially
constrained, not empty-handed.

## Sensory Progression Tables

**Smell:** Earthy/coppery → Sweet-rot/incense → Cold ash/jasmine decay → **Complete void (most terrifying)**

**Sound:** Tinnitus/pressure → Muffled → Footsteps don't match → Hearing own voice say things you didn't → **Perfect
absorbing silence**

**Temperature:**

- Surface cold (skin)
- Bone cold (骨寒) - bypasses clothing
- Heart cold (心寒) - emotional dread, not temperature
- Inverse cold - wrong spots warm/cold

**Cinema→Game:** Infrasound → low-pass filter + hum | Dark stain → spreading visual corruption | "Ma" → dust motes hang
suspended

## Appendix: The Echo Chamber Concept

> Alternative metagame structure. Not current direction, but interesting ideas.

**Core Premise:** Haunting is a Recording (Stone Tape Theory). You're an Intruder disrupting playback. Goal: end it or
escape.

**The Lodge:** Safe haven between missions. Cozy, not high-tech.

| Earn                               | Spend                            |
| ---------------------------------- | -------------------------------- |
| Resonance Points (psychic stamina) | Comforts (coffee = sanity regen) |
| Truth Fragments (story objects)    | Training (protocols)             |
| Scars (debuff + gameplay twist)    | Provisions (lost if you die)     |
| Echoes (minor stolen powers)       |                                  |
| Anchors (weaken Echo in future)    |                                  |

**Why it works:** Infinite replayability (loop always there). No mastery (can't cure trauma). Meaningful progression
without breaking horror. Become weathered survivor, not superhero.

**Wild Spark:** Bring back Anchors → Lodge has bad nights. Painting weeps. Trauma is always just a thought away.

> "This framework makes you a therapist-survivor-archivist, not a soldier."
