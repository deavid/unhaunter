# B20 - Map selector polishing for custom maps

## Symptoms

- Large, custom maps (like the Tarin Library) appear at the top of the map selector, before the refined campaign maps.
- These custom maps lack screenshots and proper sorting metadata, making the map selection confusing for players trying
  to gauge progression or map size.

## Investigation

- Low-priority polishing task.
- Check the `.tmx` files of custom maps to see if they are missing sorting properties or metadata that the refined maps
  use.
- Add missing properties (like map size / sorting order) to the `.tmx` files so custom maps are properly placed in the
  list.
- Generate and include screenshots for these custom maps.

NOTE: There's an algorithm already that is capable of counting the playable area size in squared meters for a map. This
data could be useful to add as metadata - but needs to be stored statically on the TMX.
